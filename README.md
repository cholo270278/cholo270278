## ⚡ Sobre mí

Soy **diseñador de hardware electrónico**. Me dedico a la **robótica**, la **docencia** y la **preparación de equipos de robótica educativa para competencias**.

Combino el diseño de circuitos, la programación y la integración de sistemas para transformar ideas en proyectos reales. Me interesa tanto construir tecnología como acompañar a otras personas a comprenderla, experimentar y crear.

## 🤖 Chappie · Mi proyecto destacado

**Chappie** es mi proyecto de robótica en desarrollo: un espacio donde integro electrónica, software, movimiento e interacción con las personas.

| Área | En qué estoy trabajando |
| :--- | :--- |
| Control e interfaz | Raspberry Pi 5, Python e interfaz gráfica |
| Electrónica distribuida | Integración de subsistemas con ESP32 |
| Interacción | Voz, cámara y expresiones del robot |
| Movimiento | Control e integración progresiva de actuadores |

**Foco actual:** avanzar en visión e interacción, probando e integrando cada parte del sistema.
